# 竞品分析工具 · 前列腺癌版

前列腺癌（拜耳）竞品分析的独立离线网页工具。底表在浏览器本地解析，不上传任何服务器。

## 使用
- 双击 `index.html`（或部署到 GitHub Pages 后访问在线地址）。
- 在页面上传销售底表 Excel（需包含列：`销售时间`、`商品名称`、`适应症`、`数量`、`ONEID`/`会员号`、`医疗单位`、`处方科室`、`处方医生`、`开票抬头`、`收款方式` 等）。
- 在「焦点品种」下拉选本品（如瑞维鲁胺/艾瑞恩），即可看品牌份额、趋势、医院/医生覆盖、城市分布。

## 口径说明
- 适应症统一归为「前列腺癌」大类（不分治疗线）。
- 销量 = `数量`(盒/粒)；DOT = 窗口内数量合计 ÷ 去重患者数（oneid + 开票抬头 联合去重）。
- 科室归一为泌尿外科 / 肿瘤科体系。

## 部署（GitHub Pages）
将本目录内容推到仓库（或作为子目录 `pc/`），在仓库 Settings → Pages 选择对应分支与根目录即可。
在线地址示例：`https://<user>.github.io/<repo>/pc/`

## 文件
- `index.html`：自包含单文件（xlsx / chart / qrcode / 适应症映射 全部内联），离线可用。
